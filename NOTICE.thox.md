# THOX Attribution

**ThoxHermes-webui** (ttracx/ThoxHermes-webui) is a THOX.ai-themed fork of
**Hermes Web UI** — upstream: https://github.com/nesquena/hermes-webui — licensed
MIT. The upstream `LICENSE` (© Hermes Web UI Contributors) is preserved unchanged.

Hermes Web UI is the browser interface for the **Hermes Agent** by Nous Research
(https://hermes-agent.nousresearch.com/). THOX did not author the agent or the base
web UI; all credit for those belongs to their respective projects.

## What THOX added

- A real THOX.ai design system shipped as the `thox` skin (default): zinc-first
  surfaces, emerald `#10B981` + neon `#00FF88` accents, Inter + JetBrains Mono,
  WCAG AA. See [`THOX_THEME.md`](THOX_THEME.md) and
  [`static/thox-theme.css`](static/thox-theme.css). The same token set is shared
  with **ThoxHermes-studio**.
- THOX branding and documentation.
