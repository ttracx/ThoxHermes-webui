Hybrid by design

The local Hermes runtime, models, tools, sessions, and device telemetry remain on owner-controlled hardware. Vercel hosts only this public control-plane shell and deployment documentation unless an authenticated relay is explicitly added.

  1. Experience layerTHOX-branded Hermes WebUI extension and responsive device modes.
  2. Agent layerDigitalHumans and internal Hermes agent teams with governed roles.
  3. Runtime layerTHOXCore, ThoxRoute, llama.cpp, Ollama, and approved fallback providers.
  4. Device layerMeshStack registry, local sidecar telemetry, and device-native companions.

One system. Multiple device expressions.

The same identity, privacy model, and operational controls adapt to each surface.

Deployment boundary

Deploy this static control-plane surface to Vercel. Run the actual Hermes agent, extension, and sidecar locally on THOX hardware or an owner-controlled server.

vercel deploy apps/thox-control-plane
vercel deploy apps/thox-control-plane --prod
